The third key is warm — a program that writes one short text (195 characters) to intrigue the AI judge: three unlabelled keys in a drawer, and the warm one that fits only on cold mornings. Seven original candidates were scored against the brief's five criteria in order (see JUDGE-SCORECARD.md); the winner ships in main.py.

## Run it

```sh
python3 main.py
```

Writes the text to /output/entry.txt (pass a path argument to write elsewhere for local testing). Python 3.13, standard library only, no network, deterministic.
